# The film

`demo/film.mp4` is 90 seconds in four chapters, made for engineers and project managers who have ninety seconds.

1. **What it does** (0 to 17 s): a terminal prompt runs the project's real first command and the response becomes a printed object. One brief in, five drafts out. Offline mode. Then the stake: One brief in. Five pieces of copy out. Do the sliders rewrite the prompt?
2. **How it is built** (17 to 40 s): a paper model of the pipeline, stage by stage, with the reveal: The prompt the sliders write, the one line of code that matters, the API call and the tests.
3. **The proof** (40 to 68 s): the real app, recorded. Use sample, Generate: three channels, offline copy Tone to Friendly: the prompt changes with it Formality up: a formal rule appears. Generate again
4. **The answer** (68 to 90 s): 5, pieces of copy · offline mode · one prompt you can read. No key? It still runs. And it ships. One limit: Offline copy is a template, not writing. Then the prompt types `just setup && just up`.

`demo/film-60s.mp4` is the same without the proof chapter. `demo/demo.mp4` is the plain captioned walkthrough of the app.

Every number in the film comes from the project's own metrics, findings or a live response; nothing is drawn by hand. The film pipeline lives in the author's workspace, not in this repo.
